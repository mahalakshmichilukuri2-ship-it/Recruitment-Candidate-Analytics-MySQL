# Recruitment & Candidate Analytics System

## Project Overview

The Recruitment & Candidate Analytics System is a MySQL-based database project designed to manage recruitment-related data and analyze candidate information.

The project helps store and manage information about candidates, job positions, applications, interviews, recruiters, and recruitment activities.

## Objectives

- To organize recruitment data efficiently
- To manage candidate information
- To track job applications
- To manage interview details
- To analyze candidate and recruitment data
- To generate useful insights using SQL queries

## Key Features

### Candidate Management
Stores and manages candidate details such as candidate information, skills, and experience.

### Job Management
Maintains information about available job positions and their requirements.

### Application Tracking
Tracks applications submitted by candidates for different job positions.

### Interview Management
Stores interview details and helps track the interview process.

### Recruitment Analytics
Uses SQL queries to analyze recruitment data and generate useful insights.

## SQL Analysis

The project includes SQL queries for:

- Finding candidates based on specific conditions
- Analyzing applications
- Counting candidates and applications
- Calculating averages and totals
- Grouping recruitment data
- Filtering grouped results
- Joining related tables
- Using subqueries for advanced analysis
